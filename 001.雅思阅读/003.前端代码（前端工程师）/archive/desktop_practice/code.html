考点聚焦与语法难关

  • check_circle
    主谓单复数一致性陷阱 (Subject-Verb Concord) 主语中心词为不可数名词 expansion，而非介词宾语中的复数 farms。故谓语动词采用单数现在完成时 has transformed。
  • check_circle
    长定语插叙造成的认知阻断 (Clause Interruption) 非限制性从句插入在主谓之间，容易在快速扫读 (Skimming) 时诱发主干误判，需利用成对双逗号快速跳读主干。
